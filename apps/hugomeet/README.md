# HugoMeet

**Live:** [meet.hugocabel.com](https://meet.hugocabel.com)

## Description
This is my meeting platform, it's a clone of google meet web, that I made to learning purposes.
It's using WebRTC to connect all the clients together via a [Signaling Server](https://github.com/hcabel/web-monorepo/tree/DEV/apps/hugomeet-SS)
The frontend is built with Next.js App Router and TypeScript.

It's actually pretty old but it's working and I learn a lot doing it (but I wouldn't do it like that anymore XD)
